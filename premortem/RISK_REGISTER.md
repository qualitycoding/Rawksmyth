# Pre-Mortem Risk Register (premortem/RISK_REGISTER.md)

| Risk ID | Failure Mode | Severity | Likelihood | Root Cause | Mitigating Strategy / Decision | Traces To |
|---|---|---|---|---|---|---|
| **R-001** | High latency on Windows with WASAPI Shared Mode ($>80\text{ ms}$) | High | Medium | Windows audio engine mixer buffer sizing in non-exclusive mode | Decision **D-005**: Request WASAPI Exclusive Mode by default; offer low-latency toggle; provide separate Audio Latency Offset calibration slider for shared mode. | S-002, T-019 |
| **R-002** | Octave errors on low $E_2$ ($82.41\text{ Hz}$) string | High | Medium | Standard $44.1\text{ kHz}$ window captures too few cycles within latency budget | Decision **D-002**: Multi-rate $4\times$ decimation down to $11.025\text{ kHz}$, providing 7.6 full cycles in a 1024-sample window with zero algorithmic latency penalty. | S-003, T-002, T-020 |
| **R-003** | Guitar pick attack transients causing false/chaotic pitch detection | High | High | String dynamics are inharmonic during initial pick strike ($0\text{--}15\text{ ms}$) | Decision **D-006**: `TemporalNoteTracker` with 15–35 ms consensus window and confidence voting; 2nd-order 3.5 kHz conditioning low-pass filter (D-008). | S-005, T-006 |
| **R-004** | Godot render thread jitter causing audio buffer underruns | Critical | Low | Coupling audio callback to main engine thread loop | Decision **D-003**: Thread isolation. Dedicated OS real-time audio thread communicating strictly via lock-free SPSC ring buffer (`rtrb`). Zero audio in Godot. | S-002, S-007, T-021 |
| **R-005** | Headless CI failure due to missing audio hardware | High | High | CI runners lack physical soundcards or audio endpoints | Decision **D-009**: Decouple `T-015a` (deterministic DSP throughput test on synthetic audio) from `T-015b` (physical hardware loopback test); implement `MockAudioBackend`. | S-002, S-014, T-015a |
| **R-006** | Chart parser path traversal or malformed JSON denial-of-service | Medium | Low | Unsanitized chart asset references or unbounded nesting | Decision **D-008**: Strict JSON schema with recursion limits and path validation rejecting relative `..` sequences. | S-006, T-012, T-013 |
| **R-007** | Clock drift between backing track and guitar capture | High | Medium | Using separate audio playback and capture streams | Decision **D-001**: Full-duplex audio stream callback deriving clock strictly from output sample counter. | S-002, S-008 |
| **R-008** | Inaccurate note judgments due to display lag vs audio latency | Medium | Medium | Display double-buffering / monitor latency differing from audio driver buffer | Decision **D-007**: Independent Audio and Visual offset calibration sliders in settings. | S-008, S-009, T-022 |
