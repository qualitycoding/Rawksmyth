# Research Sources & Citations (research/SOURCES.md)

1. **Mozilla Cubeb Audio Library:**
   - URL: https://github.com/mozilla/cubeb
   - Scope: Cross-platform low-latency audio I/O library for Firefox supporting WASAPI, AudioUnit, ALSA, PulseAudio, and PipeWire.

2. **McLeod, P. & Wyvill, G. (2005):**
   - Title: *A Smarter Way to Find Pitch: McLeod Pitch Method (MPM)*
   - Scope: Normalized Square Difference Function (NSDF) with parabolic peak interpolation, demonstrating high octave error resistance on stringed instruments.

3. **de Cheveigné, A. & Kawahara, H. (2002):**
   - Title: *YIN, a fundamental frequency estimator for speech and music*
   - Scope: Cumulative mean normalized difference function for accurate pitch estimation.

4. **Fletcher, N. H. & Rossing, T. D. (1998):**
   - Title: *The Physics of Musical Instruments* (2nd ed., Springer)
   - Scope: Physical analysis of plucked string transients, attack time non-linearities, and inharmonicity coefficients in electric guitar strings.

5. **godot-rust / gdext:**
   - URL: https://github.com/godot-rust/gdext
   - Scope: Rust bindings for the Godot 4 GDExtension C API, enabling native code integration without modifying Godot engine source.
